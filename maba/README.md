Чому можна просто перебрати

MBA ускладнює ручний аналіз , але не ускладнює перебір: f(c, key) як і раніше — звичайна функція одного байта в один байт. Раз домен усього 256 значень, перебір працює миттєво незалежно від того, наскільки заплутаний вираз усередині.
