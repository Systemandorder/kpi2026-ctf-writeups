**Флаг:** `kpi2026{l1n34r_4lg3br4_m0d_256_1s_s0lv4bl3}`

## Що це за файл

Нативний x64. Програма просить ввести рядок довжиною рівно 43
символи. Перевіряє його не по одному символу, а одразу через 43
формули: у кожній формулі символи флага множаться на свої
коефіцієнти, додається ще одне число, і результат порівнюється за
модулем 256 (тобто як лічильник, що рахує тільки до 256, а потім
знову з нуля) з очікуваним числом.

По суті це система з **43 лінійних рівнянь із 43 невідомими**
(невідомі — це символи флага), тільки арифметика ведеться за
модулем 256. Підібрати 43 байти руками нереально.

## Що треба зробити

1. Відкрити бінарник і знайти функцію перевірки: у ній два
   вкладені цикли — зовнішній проходить по 43 рядках перевірки,
   внутрішній для кожного рядка рахує суму добутків
   коефіцієнт × символ флага.
2. Витягти прямо з `.rdata` бінарника три таблиці байтів:
   `A` — 43 очікувані результати, `B` — 43 вільні доданки,
   `C` — матриця коефіцієнтів 43×43 (1849 байт).
3. Переписати формулу кожного рядка
   `(B[i] + сума по j від C[i][j] * flag[j]) mod 256 == A[i]` як
   окреме обмеження для **Z3** — усього 43 обмеження на 43
   невідомі байти.
4. Z3 за частку секунди знаходить єдиний набір із 43 байтів, що
   одночасно задовольняє всі 43 рівняння.
5. Перетворити ці байти на символи ASCII — вийде флаг.
